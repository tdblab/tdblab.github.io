HCR Probe Designer v2.0

Design HCR Probes

One block opens for each gene. RNA input (U) is read as T. Any other non-ACGT character is kept as N, and probes are never placed over it.
Specificity check (optional)
The file is read in your browser only; nothing is uploaded to a server.
Matches are exact stretches of 15 nt or longer, on either strand. When several genes are entered, every gene is also checked against the others.
Scoring settings
Every probe set starts at 100 and loses up to the number of points below for each property. Set a value to 0 to ignore that property.
